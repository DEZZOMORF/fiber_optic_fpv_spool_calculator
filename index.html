Як це рахується

Пошарова модель — основна. Витків у шарі та радіус кожного шару:

N = ⌊(L − 2·відступ) / d_волокна⌋ r_i = d_гільзи/2 + d_волокна/2 + (i−1)·крок крок = 0.866·d_волокна (гекс) або d_волокна (рядна) Довжина шару i = N_i · 2π · r_i

При гексагональній укладці парні шари сідають у западини непарних, тож містять на один виток менше. Об'ємна модель — швидка звірка через площу кільця:

ℓ = k · L · (D_намотки² − d_гільзи²) / d_волокна² k — коефіцієнт заповнення, для гексагональної решітки π/(2√3) ≈ 0.9069

Крок спіралі вздовж осі ігнорується: він подовжує виток у (1 + (d/πD)²)^½ разів — для Ø60 мм і волокна 250 мкм це близько +0,00009 %.

Модель описує рівномірну укладку без перехресних намоток і без натягу, що підтискає нижні шари. На реальному верстаті очікуйте на 3–8 % менше через нерівність країв та дрейф укладальника. Радіальний зазор закладено як запас на биття намотки.

# Fiber optic spool calculator

Калькулятор намотки оптоволокна на гільзу під тубусом — для FPV-котушок.

Один файл без залежностей: `index.html`. Відкривається локально або за адресою
[optic.npa.in.ua](https://optic.npa.in.ua).

## Що рахує

Гільза (Ø, довжина), тубус (зовнішній Ø, стінка) і довжина волокна пов'язані
однією геометрією. Задаєте будь-які три величини — четверта обчислюється;
натискання `=` біля поля робить шуканим саме його.

Основна модель — пошарова: витків на шар `N = ⌊L / d⌋`, радіальний крок
`0.866·d` для гексагональної (вкладеної) укладки або `d` для рядної, довжина
шару `i` дорівнює `N_i · 2π · r_i`. Сума по шарах має замкнуту форму, тож
обернені задачі розв'язуються точно, а не підбором. Поруч наводиться об'ємна
оцінка через площу кільця — для звірки.

Додатково: маса намотки, кількість шарів і витків, фактичний коефіцієнт
заповнення, перевірка мінімального радіуса згину, пресети волокна від 200 мкм
до дроп-кабелю, інтерактивні перерізи з розкладкою по шарах і витках.

## Точність

Модель описує рівномірну укладку без перехресних намоток і без натягу, що
підтискає нижні шари. На реальному верстаті очікуйте на 3–8 % менше через
нерівність країв та дрейф укладальника.
